# Test documents

Fictitious documents used to check that the pipeline generalises beyond the official challenge document. Every name, number and address is invented; any resemblance to real people is a coincidence.

- `01`–`07`: test files generated by the team to stress the pipeline: table layouts with labels and values on separate lines, IBANs split across lines, styled Unicode letters, struck-through old data, credentials (passwords, PINs, security answers), IP addresses and GPS coordinates. Formats: PDF and TXT (UTF-8 and UTF-16).
- `R01`–`R10`: realistic Portuguese documents written by the team (service contract, complaint email, call notes, HR record, termination letter, technical report, power of attorney, support chat, social tariff request, customer records CSV). Their NIF, CC, IBAN and NISS values pass the official checksums.

Run the evaluation:

```bash
cd submission
python -m anonimizador.evaluate_docs data/test_docs
```

A reference answer named `<document>.gold.txt` next to a document adds Similarity and Accuracy to the report.
